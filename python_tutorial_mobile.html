1.1 什么是 Python？

Python 由 Guido van Rossum 于 1991 年创造，是一种解释型、面向对象的高级编程语言。设计哲学强调代码可读性——Python 代码看起来就像英语。

class Vector2D:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    def magnitude(self):
        return (self.x**2+self.y**2)**0.5

7.2 数值微积分入门

数值导数

Python
def derivative(f, x, h=1e-7):
    return (f(x+h)-f(x-h))/(2*h)
print(derivative(lambda x:x**2, 3)) # ≈6.0

数值积分（黎曼和）

Python
def integral(f, a, b, n=100000):
    dx=(b-a)/n
    return sum(f(a+i*dx)*dx for i in range(n))
print(integral(lambda x:x**2,0,1)) # ≈0.3333

7.3 蒙特卡洛方法——用随机数估算 π

Python
import random
N = 1000000
inside = 0
for _ in range(N):
    x = random.uniform(-1, 1)
    y = random.uniform(-1, 1)
    if x**2+y**2 <= 1:
        inside += 1
print(f"π ≈ {4*inside/N}")
🎓 大学关联：蒙特卡洛方法在金融数学、贝叶斯统计中广泛应用。UCL 的统计课程会深入探讨。

7.4 牛顿迭代法求平方根

Python
def newton_sqrt(n, iters=10):
    x = n
    for _ in range(iters):
        x = (x + n/x)/2
    return x
print(f"√2 ≈ {newton_sqrt(2):.15f}")
