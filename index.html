6.1 类与对象——蓝图与实物

类（Class）是创建对象的蓝图，就像饼干模具。对象（Object）是类的具体实例，就像用模具做出的饼干。

Python
class Vector2D:
    """二维向量——数学中最基础的数据结构之一"""
    def __init__(self, x, y):
        self.x = x    # 向量的 x 分量
        self.y = y    # 向量的 y 分量

    def magnitude(self):
        """计算向量的模（长度）|v| = √(x²+y²)"""
        return (self.x**2 + self.y**2) ** 0.5

    def __str__(self):
        return f"Vector({self.x}, {self.y})"

v = Vector2D(3, 4)
print(v)                # Vector(3, 4)
print(v.magnitude())    # 5.0（勾股定理！√(9+16)=5）

7.2 数值微积分入门

🔬 数值导数（中心差分法）

基于导数极限定义：f'(x) ≈ [f(x+h) − f(x−h)] / (2h)，取 h = 1e-7。

Python
def derivative(f, x, h=1e-7):
    """用中心差分法求 f'(x)"""
    return (f(x + h) - f(x - h)) / (2 * h)

# f(x)=x², f'(x)=2x → f'(3)=6
print(derivative(lambda x: x**2, 3))   # ≈ 6.0000 ✓

# f(x)=sin(x), f'(x)=cos(x) → f'(π/4)=√2/2≈0.7071
result = derivative(math.sin, math.pi/4)
print(f"sin'(π/4) ≈ {result:.6f}")  # ≈ 0.707107 ✓

∫ 数值积分（黎曼和）

Python
def integral(f, a, b, n=100000):
    """用矩形法近似计算 ∫ₐᵇ f(x) dx"""
    dx = (b - a) / n
    total = sum(f(a + i*dx) * dx for i in range(n))
    return total

# ∫₀¹ x² dx = 1/3 ≈ 0.3333
print(integral(lambda x: x**2, 0, 1))       # ≈ 0.3333 ✓

# ∫₀¹ 4/(1+x²) dx = π ≈ 3.1416
print(integral(lambda x: 4/(1+x**2), 0, 1)) # ≈ 3.1416 ✓
💡 前置学习：这些数值方法正是大学「数值分析」课的核心内容。提前用 Python 动手实现，上课时你会比别人理解得更深刻。在大一的 Calculus 和 Linear Algebra 课程中，你可以用这些代码验证作业答案。

7.3 蒙特卡洛方法——用随机数估算 π

核心思想：在 [-1,1]×[-1,1] 正方形内随机撒 N 个点，统计落在内切圆（x²+y²≤1）内的比例。圆面积 / 正方形面积 = π/4 ≈ 圆内点数 / N。

Python
import random

N = 1000000  # 撒 100 万个随机点
inside = 0

for _ in range(N):
    x = random.uniform(-1, 1)  # 随机 x 坐标
    y = random.uniform(-1, 1)  # 随机 y 坐标
    if x**2 + y**2 <= 1:       # 判断是否在圆内
        inside += 1

pi_approx = 4 * inside / N
print(f"π ≈ {pi_approx}")
print(f"误差: {abs(pi_approx - 3.14159265):.6f}")
▸ 典型输出（每次运行略有不同）
π ≈ 3.141872
误差: 0.000279 ← 非常精确！

7.4 牛顿迭代法——二次收敛的求根算法

牛顿迭代公式：xₖ₊₁ = xₖ − f(xₖ)/f'(xₖ)。对于 f(x) = x² − n（求 √n），化简得：xₖ₊₁ = (xₖ + n/xₖ) / 2

意思是：每一步的猜测值 = （上一步猜测值 + n/上一步猜测值）/ 2。收敛极快，每次迭代精度翻倍（二次收敛）。

Python
def newton_sqrt(n, iters=10):
    """牛顿迭代法求 √n——收敛速度极快！"""
    x = n  # 初始猜测值
    for i in range(iters):
        x = (x + n / x) / 2
        print(f"第 {i+1} 次迭代: x = {x:.10f}")
    return x

print("计算 √2:")
result = newton_sqrt(2)
print(f"√2 ≈ {result:.15f}")
▸ 输出结果
第 1 次迭代: x = 1.5000000000
第 2 次迭代: x = 1.4166666667
第 3 次迭代: x = 1.4142156863
第 4 次迭代: x = 1.4142135624
第 5 次迭代: x = 1.4142135624
√2 ≈ 1.414213562373095
🔍 观察：仅 5 次迭代就达到了 10 位精度！这就是二次收敛的威力——每一步的准确位数大约翻倍。牛顿法是数值分析中最优雅的算法之一。
